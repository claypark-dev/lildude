The Lil Dude Philosophy

We built Lil Dude because the AI agent space got weird. Hundreds of vulnerabilities left unfixed. Marketplaces full of malware. Monthly bills that cost more than rent. Agents that run code without asking. That's not the wave we want to ride.

Lil Dude is the agent for people who want powerful autonomy with a kill switch. Self-hosted so your data stays home. Cost-capped so your API bill doesn't eat your paycheck. Security-first so you can sleep at night.

Think of it like surfing: you read the ocean, choose your wave, and ride it on your own terms. Lil Dude is the board. The waves are the skills. Shorebreak builds new boards when you need them. And you're always the one who decides when to paddle out.

Quickstart Guide

From zero to riding in 5 minutes. Here's the complete flow.

1. Install & Onboard

git clone https://github.com/claypark-dev/lildude.git cd lildude && npm install npx lil-dude onboard # walks you through API keys, channels, security npx lil-dude start # launches with dashboard

2. Browse & Install Waves

Waves are skills that extend what your assistant can do. Browse 967 community waves on Shorebreak, or install directly:

lildude wave install weather-checker # observe tier (read-only) lildude wave install todo-manager # create tier (adds data) lildude wave install email-template # observe tier lildude wave list # see installed waves

3. Connect Channels

Talk to your assistant from anywhere. Enable channels during onboarding or edit lildude.config.json:

# Supported: Discord, Telegram, Slack, iMessage, WhatsApp, Signal, # Matrix, Teams, LINE, Google Chat, WebChat, CLI # WebChat + CLI are enabled by default

4. Customize Your Agent

Give your assistant a name, set a persona, and configure standing instructions for the heartbeat system:

# In lildude.config.json: "agent": { "name": "Jarvis", "persona": "a witty British butler AI" } # Edit ~/.lil-dude/heartbeat.md for proactive checks: # "Check my calendar every 30 minutes" # "Alert me if my API spend exceeds $5 today"
