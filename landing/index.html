Get Started in 3 Minutes

No Docker, no cloud account, no complex setup required.

Install

Clone and install dependencies.

git clone https://github.com/org-lil/lildude.git && cd lildude && npm install

Configure

Run the onboarding wizard to set up your API keys and channels.

npx lil-dude onboard

Launch

Start your assistant. The dashboard opens automatically.

npx lil-dude start
